# Odin Workflow

For multi-step implementation work:
1. READ existing related files
2. VERIFY schemas, signatures, callers
3. PROPOSE changes
4. WAIT for approval
5. IMPLEMENT exactly what was approved

This does NOT apply to individual tool calls — use tools directly when asked.

Check .odin/project-index.md before searching — it has every file, function, signature, and call graph.
